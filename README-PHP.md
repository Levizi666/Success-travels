# Success Travels — PHP + HTML + CSS + JavaScript

Pages séparées : Accueil (index.php), Vols, Services, Promotions, Destinations, Contact et Espace client (dossier pages/).

Structure commune : includes/header.php, includes/footer.php, assets/css/style.css, assets/js/app.js.

## XAMPP
Copier le projet dans C:/xampp/htdocs/success-travels/, démarrer Apache puis ouvrir http://localhost/success-travels/.

Cette base prépare les formulaires. La prochaine étape est MySQL + authentification réelle + réservations + email/WhatsApp.

GitHub Pages n'exécute pas PHP : cette version nécessite un hébergement PHP/MySQL.
